# EGO 上游差异边界

固定提交及完整归档校验值见 `third_party/UPSTREAMS.json`；两套源码的原始许可证保留。

## EGO-Swarm ROS 2

- 将规划管理器、优化器和可视化中的独立系统时钟改为所属节点的仿真时钟，修正以 Unix 纪元判断“尚未规划”的条件。
- 原手动目标回调固定使用 1 m 高度，改为读取目标消息 Z。
- 点云使用 SensorDataQoS，接收经过测量时刻 TF 转换的世界 XYZ。室内点云入口接 OctoMap 的已测障碍，保留固定栅格缓存。
- 点云入口的 Z 轴膨胀从固定一个栅格改为与 XY 一样按安全半径计算。
- 增加执行许可和速度上限订阅；轨迹拒绝后清除旧目标，从反馈状态重新规划。

## EGO-Planner-v2

- 仅使用 `swarm-playground/main_ws`。将构建和消息生成迁移到 ament/rosidl；消息类型改为 ROS 2。
- `ros2_adapter` 封装 ROS 2 发布、订阅、参数和仿真时钟定时器，保留上游调用结构，不依赖 ROS 1。
- 不连接原相机深度同步管线；通用点云已在外部转换到世界坐标，地图中的相机固定旋转改为单位变换。
- 保留 `grid_map.cpp` 环形缓存、MINCO、L-BFGS、动态 A* 和原生五次多项式。
- 增加与室内相同的执行许可和规划速度更新。

## 共同接入层

`ego_bridge` 将原控制点／结点或多项式系数按原顺序传输到 `NativeTrajectory`。通用层直接求导和求值，不重新拟合规划轨迹。航向、观测检查、制动和 GanYu 输入属于接入层。紧急制动使用独立曲线，正常 EGO 轨迹保持原表达。

根工作空间、Swarm 和 v2 分别构建。禁止同时加载两个后端的安装环境。

- 两套 FSM 的目标切换移除了回调内部的嵌套 executor spin，避免重新规划时重复把节点加入执行器。
- 发布规划耗时和成功状态，耗时使用单调墙钟；仿真时钟继续负责轨迹时间，暂停时不会推进轨迹。
- 轨迹桥在执行许可被撤销、目标尚未发出或轨迹早于当前目标时过滤旧消息，避免迟到轨迹干扰新目标。
- 两套 FSM 每次只允许一条候选轨迹等待接管。桥保留公共 ID 与原生 ID 的对应关系，GanYu 真正接受该参考后才确认给 FSM。候选拒绝与执行停止分开：当前已接管轨迹仍安全且速度上限未下降时保留原参考，桥重置上游 FSM 后以同一目标从测量状态重规划，并过滤重置前的迟到候选。实际制动、数据失效或人工退出则取消待重试目标，不能自行恢复。新目标可取代尚未确认的候选；转向和观察阶段不发布 EGO 目标。此逻辑属于通信接入层，未修改两套原生优化器。
- 原地观察仍不足时，任务层可单独执行已测空间内的小范围观察位移。该机动及其完整制动曲线先通过观测与动力学检查，不由 EGO 轨迹重新拟合而来；正常任务段仍直接执行原生 B 样条或 MINCO。

- 两套地图的膨胀核统一为球形安全间距加体素余量，避免立方体角部把安全位置误判为占据。v2 的同一插入／移除函数使用相同核；环形缓存容量与索引机制保留。
- v2 的默认局部目标若落在已测障碍内，继续在原全局参考上、当前局部窗口内寻找空闲目标；无远端空闲点时使用较近空闲点并停车。连接路径仍由原动态 A* 与 MINCO 计算，不读取评测通道。
- v2 低速配置提高可行性与时间代价的比例，弥补原生六次速度惩罚在低速下变弱；优化器数学实现未改动。
- v2 更新规划速度时也预留 20% 余量，防止软约束轨迹在低速下反复略超执行门槛；不裁剪输出参考。原生 MINCO 低速回归在请求 0.18 m/s 时实测最大速度 0.146 m/s，检查位置／速度／加速度／jerk 原系数求值。
- v2 的旧全局种子可能保留降速前的局部目标速度。更新原生局部目标的边界速度，使新 MINCO 求解满足当前上限；原优化公式和输出采样保留。动态降速回归先复现 0.18 m/s 请求下仍输出 0.284 m/s，修复后为 0.144 m/s。约束采样由每段 5 点增至 15 点，改善低速长分段的离散检查。
- Swarm 低速配置也提高可行性代价权重。输入规划速度预留 20% 余量，并按三轴分量转换；速度更新接口允许该低速输入，避免执行层降速后规划器仍使用较高旧上限。优化器目标公式和 B 样条表示保留，执行限值不放宽。
- Swarm 原生细化后补充可行性复核和最多五次重试。若原有仅内部结点调时后仍不可行，规划器内部统一缩放原生结点时间，再使用原有边界约束和优化器；不足内部结点的短轨迹避免零／负区间。该兼容性修复不改优化器目标公式，不在 GanYu 接入层重拟合轨迹。低速斜向返航回归同时核验全向及单轴限值。
- 规划诊断报告原生占据和膨胀缓冲容量；独立评测同时核验原生缓存与通用观测缓存的容量。
- Swarm 沿用原有虚拟天花板的栅格平面表示，补充可选虚拟地板，使规划阶段识别仓库高度下界。默认关闭，不改变地图缓存结构或轨迹优化器；执行层高度门槛不放宽。原始 B 样条的仓库高度带、低速返回、接管和膨胀回归均通过。
