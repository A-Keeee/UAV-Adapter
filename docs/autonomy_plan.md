# 本轮实施与验收范围

本文件记录会话最后确认的实施方案，替代较早的自建仓库与必填雷达能力配置方案。实施证据与未完成项见 [实施记录](autonomy_implementation.md)；运行方式见 [任务说明](../uav_autonomy/README.md)。目标与已经通过的验收分别记录，不能互相替代。

## 两项任务

- 仓库：AWS Small Warehouse 完整带屋顶版本，固定提交 `ee0af733315e78432408c3cd98d378ecee5f767c`。建筑约 14×21 m，屋顶约 9–10 m，固定地图缓存 24×32×12 m。OctoMap 从空白建图，三维 Frontier 选择观察目标，EGO-Swarm 原生 B 样条规划，GanYu 跟踪。完成探索、保存地图、至少四个不同位置和高度的巡检点、返航与降落；同一仿真会话保持定位原点一致。
- 树林：本地 PX4 Forest 与松树／橡树资源，固定提交 `e05f4312d3f28aa621157610584a4870406cb6d3`；保留原版并制作 80 m 长航程版本。EGO-v2 `main_ws` 原生环形地图与 MINCO，默认窗口 20×20×8 m、0.2 m 分辨率，局部地图和观测缓存容量有界，不保存全局地图。目标 B 可位于窗口之外，完成 A→B、悬停与安全区降落。

导航不读取场景碰撞几何、树木坐标或评分通道。仅明确配置起降净空、任务目标与允许飞行高度；当前仓库起飞高度 3.8 m、执行高度 3.7–5.7 m，树林起飞高度 1.8 m、执行高度 1.5–2.3 m。高度配置不是雷达能力。

## 雷达接口

MID-360、Livox Avia、Ouster OS1-64 仅由仿真端选择扫描预设、安装变换与载荷。导航端不读取其型号、FOV、盲区、线数或硬件量程，也不以能力配置作为启动前置条件。未知型号可直接通过任意外部 PointCloud2 话题和正确 TF 接入，不改源码、不重新编译。

最低要求是可解析的米制 XYZ、可与飞机状态对应的采样时间、点云坐标系及真实测量原点。世界坐标云须另外提供测量原点。有效端点和射线更新地图；无回波保持未知，计算窗口不代表硬件量程，射线截断位置不产生假障碍。

ODIN1 已由用户排除，不列为本轮待交付项。首批使用 PX4 仿真定位，不包含真实硬件飞行、雷达里程计或跨重启地图重定位。

## 规划与控制

EGO-Swarm 固定 `23a8d5a191711dd65633df689bd00f55d4dea8f9`，EGO-v2 固定 `9d85475ea7b9bf5c112cf7c3c3d0d3f9e96d9010`，后端独立构建／加载。保留原优化器、地图机制和轨迹表示，必要兼容补丁单独记录。

直接从原 B 样条／五次多项式计算 p/v/a/jerk，不重新拟合轨迹。GanYu 以 200 Hz 使用原平移控制律，接收外部航向与航向角速度；统一时间、ENU/FLU 与 NED/FRD 变换、执行确认、撤销与接管。同机仅一套控制输出，人工退出 Offboard 后停止接管。

默认 V/A/J 上限 1 m/s、0.7 m/s²、1.5 m/s³，未知传感器从 0.5 m/s 开始，观测不足时降低规划速度、转向或在已测空间换观察位置；完整制动空间不成立则停车并报告。正常任务降落与故障悬停分别记录。保留原键盘、A* 航点和启动入口。

## 验收与交付

首轮矩阵为两任务×三雷达×三组固定初始航向（0、+π/4、−π/4），共 18 个配置；不是三个不同树林种子。失败或缺少独立评分不能计入通过，重试保留原始记录，按每个配置的最新尝试汇总。不同树林种子可在基础矩阵通过后扩展，不能将初始航向变化称作场景种子变化。

独立 Gazebo 评分要求：正常任务零碰撞，飞行阶段障碍间距至少 0.65 m，航点误差不超过 0.25 m，真值跟踪 RMSE 不超过 0.15 m；仓库保存地图对独立定义的可观测区域覆盖率不少于 90%；树林验证完整 80 m 航程和缓存容量有界。真值不反馈给导航。

另行验证匿名输入、XYZ 布局变化、稀疏／裁剪／低频／空帧／超载、时间和 TF 异常，以及点云暂停、状态暂停、人工退出 Offboard 和封路。接口回放、软件回归与未解锁场景检查不代替完整飞行。
